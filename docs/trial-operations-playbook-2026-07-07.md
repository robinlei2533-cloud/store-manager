## 粉丝如何兑奖

1. 粉丝进入粉丝中心，打开积分兑换区。
2. 选择奖品并点击兑换。
3. 系统扣除积分，生成唯一兑奖码，状态为待核销。
4. 粉丝到附近 S 级 UWELL 门店，向店员展示兑奖码。
5. 店员在门店中心输入兑奖码，核销成功后交付奖品。
6. 系统把兑奖记录改为已领取，并扣减该门店对应奖品库存。

## 门店如何核销

1. 门店员工用 S 级门店账号进入门店端。
2. 打开奖励核销区域，输入粉丝展示的兑奖码。
3. 系统检查兑奖码是否存在、是否过期、是否已使用、门店是否为 S 级、库存是否充足。
4. 页面显示可核销后，店员先核对奖品名称，再把实物交给粉丝。
5. 粉丝拿到奖品后，店员点击确认核销。
6. 成功后不要再次交付同一兑奖码，重复核销会被系统拒绝。

## S 级门店责任和奖励

S 级门店责任：
- 只在系统显示核销成功后发放奖品。
- 不接受截图涂改码、过期码、已使用码、非平台生成码。
- 核对奖品名称和数量，避免发错奖品。
- 维护门店奖品库存，库存不足时及时向业务或运营申请补货。
- 不向粉丝额外收费，不私下兑换，不绕过系统记账。

S 级门店奖励：
- 优先获得官方兑换奖品库存。
- 优先获得 UWELL 灯箱、亚克力展架、陈列物料。
- 核销准确、服务记录好、库存差异低的门店优先进入活动名单。
- 月度核销记录可作为评级、激励和后续市场支持依据。

违规处理：
- 错误核销、私下兑换、库存长期不一致会影响门店等级。
- 严重或重复违规可暂停兑奖权限。

## 出错时怎么处理

| 场景 | 一线处理 | 后台处理 |
|---|---|---|
| 兑奖码不存在 | 请粉丝重新打开粉丝中心复制最新码 | 后台按粉丝手机号、邮箱或兑换记录查询 |
| 兑奖码已使用 | 不发奖，告知该码已经核销 | 查领取时间、门店、操作人，必要时联系运营 |
| 兑奖码过期 | 不发奖，引导粉丝联系运营 | 运营决定是否人工补偿或重发 |
| 非 S 级门店无法核销 | 引导粉丝去 S 级门店 | 后台确认门店等级是否需要调整 |
| 库存不足 | 不先发奖，登记缺货并联系业务补货 | 库存页确认该奖品门店库存并安排调拨 |
| 粉丝称积分被扣但没有码 | 记录粉丝账号和时间 | 后台查积分流水和兑换记录 |
| 门店误点确认 | 立即上报，不重复发奖 | 后台查出库记录、兑奖记录和审计记录 |

## 后台怎么查记录

常用路径：
- 粉丝列表：查粉丝账号、积分、等级、绑定门店。
- 粉丝详情：查积分流水、扫码、兑换相关记录。
- 物料库存：查奖品或物料库存，确认 S 级门店是否有库存。
- 出库记录：查核销后生成的出库流水。
- 门店详情：查门店等级、负责人、拜访和评分记录。
- 审计日志：上线后用于追踪关键操作人和时间。

核销闭环排查顺序：
1. 先查粉丝兑换记录，确认兑奖码状态。
2. 再查门店等级，确认是否 S 级。
3. 再查门店库存，确认奖品是否可扣减。
4. 最后查出库记录，确认是否已经完成实物交付。

## 封版安全清单

- 已在代码种子中移除 `admin/admin` 试运营密码。
- Vercel 环境变量必须锁定：
  - `VITE_SUPABASE_URL`
  - `VITE_SUPABASE_ANON_KEY`
  - `VITE_ALLOW_LOCAL_AUTH_FALLBACK=false`
  - `VITE_ALLOW_LOCAL_DB_FALLBACK=false`
- 已在聊天中出现过的 Supabase token 和 Vercel token 必须在各自控制台废弃并重新生成。
- Supabase Auth 里的真实预览账号密码需要同步改为本手册账号表中的新密码。
- 真实库存上线前至少准备一个 S 级门店、一个可兑奖奖品、明确初始库存数量。
